# Untertitel (Deutsch), Entwurf

Reine Textdateien, eine Zeile pro Untertitel, ohne Zeitmarken. Die Zeitmarken hat YouTube selbst:

1. YouTube Studio → Untertitel → Sprache Deutsch hinzufügen.
2. „Mit Text-Timing“ (Text einfügen) wählen, Datei-Inhalt einfügen, „Zeiten festlegen“.
3. Vor dem Veröffentlichen anschauen und Zeiten prüfen.

Stand: Rohtexte korrigiert, von Moni noch nicht gegengelesen. Die Zeilen mit „[Name]“ und „[unverständlich]“ vorher klären.
Die Landessprache (Lao) folgt erst, wenn ein Muttersprachler sie geprüft hat.
