# Untertitel (Deutsch), Entwurf

Reine Textdateien, eine Zeile pro Untertitel, ohne Zeitmarken. Die Zeitmarken hat YouTube selbst:

1. YouTube Studio → Untertitel → Sprache Deutsch hinzufügen.
2. „Mit Text-Timing“ (Text einfügen) wählen, Datei-Inhalt einfügen, „Zeiten festlegen“.
3. Vor dem Veröffentlichen anschauen und Zeiten prüfen.

Stand: Deutsche Texte von Moni gegengelesen. Einwilligungen (auch der Sorgeberechtigten der Kinder) liegen laut André vor. Offen: „[Name]“ und „[unverständlich]“ (eine Stelle in Video 1).
Die Landessprache (Lao) folgt erst, wenn ein Muttersprachler sie geprüft hat.

## Lao (`*.lo.txt`): maschineller Entwurf
Auf Wunsch von André automatisch erstellt (Zeile für Zeile passend zu den deutschen Dateien). **Kein Muttersprachler hat sie geprüft.** Eigennamen stehen in Lao-Schrift („ໂຢຮັນນາ“). Ein Schimpfwort ist abgemildert („ບ້າໆ“); ein Muttersprachler soll entscheiden. Nicht auf den Seiten angezeigt (Sprachumschalter bleibt aus), nur für den YouTube-Upload gedacht. Vor dem Hochladen von einer Lao sprechenden Person lesen lassen.
